# Lumen website

The Lumen landing page: one self-contained file, `index.html` (fonts and scripts are packed inside it).

The download buttons link to the newest builds in the public
[ErmendQ/lumen-releases](https://github.com/ErmendQ/lumen-releases) repo, under fixed names that always serve
the latest version:

- Windows: https://github.com/ErmendQ/lumen-releases/releases/latest/download/Lumen-Windows-Setup.exe
- Mac: https://github.com/ErmendQ/lumen-releases/releases/latest/download/Lumen-Mac.dmg
